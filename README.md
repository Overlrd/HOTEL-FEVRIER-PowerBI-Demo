# HOTEL-FEVRIER-PowerBI-Demo

Démo Power BI destinée au pilotage DAF de l'Hôtel 2 Février.

- Projet Power BI : `Odoo_PowerBI_Demo.pbip`
- Source : classeur Excel SharePoint maintenable
- Registre documentaire : table Excel `Documents` + fichiers SharePoint
- Contrat de source documentaire : `DOCUMENTS_SOURCE.md`
- Contrat fiscalité et conformité : `COMPLIANCE_SOURCE.md`
- Guide d'ouverture : `OUVRIR_LE_RAPPORT.txt`
- Guide de support et définitions : `GUIDE_SUPPORT.md`

Le modèle sémantique conserve la culture `en-US` requise par la synchronisation Fabric ; l'affichage utilisateur reste en français.

La page **Fiscalité & conformité** est une démonstration de pilotage. Ses données, statuts et justificatifs sont fictifs et ne constituent ni un avis juridique ou fiscal, ni une preuve administrative.
